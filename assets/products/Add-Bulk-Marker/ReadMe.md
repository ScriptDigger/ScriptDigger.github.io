# Add Bulk Marker

![Ae Script Free Download](https://ScriptDigger.github.io/assets/products/Add-Bulk-Marker/Add-Bulk-Marker.jpg)

Add multiple After Effects markers at once by entering one comment per line, then apply them to the selected layers or directly to the composition.

## How to Use

1. Open a composition in After Effects.
2. Enter your marker comments — one comment per line.
3. Move the playhead to the desired starting position.
4. Click **Add to Layers** to add the markers to all selected layers, or **Add to Comp** to add them to the composition.

Markers are created consecutively at **one-frame intervals**, starting from the current playhead position.

## Features

- Add multiple markers in one click
- Apply markers to multiple selected layers
- Apply markers directly to the composition
- Starts from the current playhead position
- One comment per marker
- One-frame spacing between markers
- Undo supported
- Dockable After Effects ScriptUI panel

## Installation

Copy the script file to:

```text
Adobe After Effects/Support Files/Scripts/ScriptUI Panels/
```

Restart After Effects, then open it from:

```text
Window → Add Bulk Marker
```
