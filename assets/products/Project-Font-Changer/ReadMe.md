# Font Changer

Font Changer is an After Effects script for finding fonts used in your project and quickly applying a selected font to text layers.

## How It Works

1. Open your After Effects project.
2. Run **Font Changer**.
3. Search for a font to find where it is used in the project.
4. Select the font you want to replace.
5. Choose the target:
   - **Selected Composition** — change the font only inside the selected composition.
   - **Entire Project** — change the font across the whole project.
6. Apply the change.

The script searches the project for text layers using the selected font, so you can quickly replace fonts without manually checking each composition.

## Features

- Search fonts used in the project
- Find compositions and text layers using a font
- Replace fonts in a selected composition
- Replace fonts across the entire project
- Useful for quickly updating typography in large After Effects projects

## Requirements

- Adobe After Effects
- ExtendScript-compatible version of After Effects

## Usage

Use **Search** to scan the project and list the fonts currently being used.

After selecting a font, choose whether you want to apply the replacement to the **selected composition** or the **entire project**.

> Always save a backup of your project before performing a project-wide font replacement.
