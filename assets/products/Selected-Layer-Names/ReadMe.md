# Selected Layer Names

A simple After Effects script for quickly viewing and renaming multiple selected layers at once.

## How to Use

1. Open a composition in After Effects.
2. Select the layers you want to rename.
3. Click **Get Names** to load the selected layer names.
4. Edit the names in the text box, one name per line.
5. Click **Set Names** to apply the new names to the selected layers.

Each line corresponds to one selected layer.

## Installation

Copy the `.jsx` file to:

**Windows**
`Adobe After Effects > Support Files > Scripts > ScriptUI Panels`

**macOS**
`Adobe After Effects > Scripts > ScriptUI Panels`

Restart After Effects, then open it from:

**Window > Selected Layer Names**
