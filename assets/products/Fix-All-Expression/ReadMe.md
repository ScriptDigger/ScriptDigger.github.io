## Overview
A utility script for Adobe After Effects that refreshes expressions across the entire project by temporarily disabling and re-enabling them.

## How to Use
1. Open your After Effects project.
2. Run the script (`File > Scripts > Run Script File...`).
3. Wait for the scan to finish.
4. Review the report showing fixed expressions, failed expressions, and scanned properties.

## What It Does
- Scans all compositions and layers.
- Checks expressions across properties, including transforms, shapes, text, effects, masks, and layer styles.
- Attempts to refresh each expression without changing its code.
- Displays a summary of the results.

## Notes
- Save your project before running the script.
- The script attempts to refresh expressions; it does not repair invalid expression code or guarantee that every expression will work correctly afterward.
