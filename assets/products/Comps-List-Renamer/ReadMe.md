## Overview
Selected Names is a simple Adobe After Effects script that lets you quickly export the names of selected project items to a text box and rename them by editing the list.

## Features
- **Get Selected Names:** Copies the names of selected project items into the text box, with one name per line.
- **Set Selected Names:** Renames selected project items using the names entered in the text box.
- **Flexible Matching:** Processes only the matching number of items and names.
- **Undo Support:** Renaming operations are grouped into a single undo step.

## How to Use
1. Open your project in Adobe After Effects.
2. Select the items you want to rename in the Project panel.
3. Run the script.
4. Click **Get Selected Names** to load the selected item names into the text box.
5. Edit the names, keeping each name on a separate line and preserving the order.
6. Select the same project items again in the same order.
7. Click **Set Selected Names** to apply the new names.

## Important Notes
- The script works with selected items in the Project panel, not timeline layers.
- The order of selected items determines which name is assigned to each item.
- Empty lines are ignored and do not rename the corresponding items.
- If there are more items than names, or more names than items, only the matching number of entries is processed.
- If no project items are selected, the script displays a warning.

## Requirements
- Adobe After Effects
- A JavaScript-compatible After Effects scripting environment
